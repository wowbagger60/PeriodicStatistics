# PeriodicStatistics

[Deutsch](README.de.md) | English

IP-Symcon library by Ueli Schweizer / Cassanis Automation.

| Module | Description |
|---|---|
| [PeriodicStatistics](PeriodicStatistics/README.md) | Minimum, maximum, averages, difference and integral of numeric variables per freely definable time window |

## Requirements

IP-Symcon 8.1 or later.

## Installation

Via the Module Store, or in Module Control with the URL
`https://github.com/wowbagger60/PeriodicStatistics`.
